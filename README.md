## Featured Work

### 1. [CodeCanvas](https://github.com/prashanth-karanam/CodeCanvas)
- **Live Demo**: [prashanth-karanam.github.io/CodeCanvas](https://prashanth-karanam.github.io/CodeCanvas/)
- **Summary**: A client-side web workspace unifying a live multi-language code editor with a spatial whiteboard for architecture planning and rapid UI prototyping.
- **Stack**: Vanilla JavaScript (ES6+), HTML5 Canvas API, CSS3 Flex/Grid, GitHub Pages.

### 2. [Luna Voice Assistant](https://github.com/prashanth-karanam/luna-assistant)
- **Summary**: An experimental Android client featuring a minimalist non-intrusive overlay UI and automated CI/CD builds for continuous APK delivery.
- **Stack**: Kotlin, Jetpack Compose, Material 3, Android SDK (API 34), Gradle, GitHub Actions.

### 3. [SRM Companion](https://github.com/prashanth-karanam/srm-companion)
- **Summary**: A hybrid mobile and web utility built for campus workflows, featuring session management, calendar integration, and a decoupled Node.js bridge.
- **Stack**: JavaScript, Capacitor (Android/iOS targets), Node.js, Baileys WebSocket protocol, Docker.

## Local Development

This portfolio is built with zero runtime dependencies and can be previewed directly in any modern browser:

```bash
git clone https://github.com/prashanth-karanam/portfolio.git
cd portfolio
# Serve locally via Python HTTP server
python -m http.server 8080
```

Open `http://localhost:8080` to view the site.
